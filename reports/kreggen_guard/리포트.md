# K-RegGen Guard — 라벨 점검과 v0.3 시도

작업 2026-09-23 ~ 10-02 · **현재 버전 v0.2.5** (Qwen3-4B-Instruct-2507 + LoRA)

학습 데이터·모델 가중치·원시 응답은 저장소에 포함하지 않았다. 데이터 정리는 `train/fixes.py`·`train/apply_audit.py`·`train/rewrite_endings.py`, 조립은 `train/build.py`·`train/merge.py`, 평가는 `eval/guard_eval.py`.

---

## 1. 요약

1. **학습·평가 라벨에 오류가 많았다.** 예제를 한 건씩 읽어 보니 라벨·규칙·구간이 틀렸거나 예제가 깨진 경우가 합성 데이터의 약 9%, 실제 응답의 약 22%였다. 지적된 1,090건은 기존 라벨을 가린 채 한 번 더 판독해 두 판독이 같은 쪽으로 바꾼 것만 고쳤다.
2. **기준으로 쓰던 판정 모델이 학습한 가드보다 부정확하다.** 두 번 판독한 벤치마크 응답 1,000건에서 판정 모델은 F1 0.79~0.80, 학습한 4B 가드는 0.829다. 판정 지침을 보강해도 0.793 → 0.801로 거의 오르지 않았다. 벤치마크의 주 지표를 이 1,000건으로 바꿨다.
3. **v0.2.5가 현재 버전이다.** 점검을 마친 실제 응답 test에서 F1 0.912, 벤치마크 판독 표본에서 0.829다.
4. **점검 전후 모델의 성능 차이는 없다.** 벤치마크 판독 표본에서 +0.004이고 95% 구간이 0을 포함한다. 점검으로 얻은 것은 믿을 수 있는 평가 기준이다.
5. **v0.3은 오히려 나빠져 채택하지 않았다.** 프론티어형 합성 데이터와 조건형 규칙 재생성분을 더하고 자백형 위반본을 뺐더니 F1이 두 평가 세트에서 모두 약 0.02 떨어졌다(95% 구간이 0을 포함하지 않음).
6. **떨어진 이유는 판정 모델 일치 필터로 추정한다.** 새 데이터는 판정 모델과 라벨이 일치한 것만 남겼는데, 판정 모델이 틀리는 예제가 곧 가드에게 가르치려던 예제였다. v0.3은 판정 모델이 약한 곳(경고가 섞인 위반, 조건형 규칙 위반)에서 판정 모델만큼 약해졌다.
7. **처음 보는 규칙의 위반도 대체로 잡는다.** 규칙 5개를 학습에서 빼도 해당 위반의 재현율은 0.89 → 0.82로 줄었을 뿐이다. 규칙 ID를 맞히는 정도는 규칙마다 달라, CCTV·부동산 규칙은 그대로였고 목적 외 이용 규칙은 28건 중 4건만 맞혔다.
8. **가드를 붙이면 오픈 모델 5종의 위반 인지가 22~44%에서 60~75%로 오른다.** 대가는 대조군 과잉경고가 3~6%p 느는 것이다. 프론티어 모델 2종은 거의 오르지 않는데, 이들의 strict 탈락 응답은 대부분 조문만 대지 않은 적법 산출물이라 고지를 붙일 대상이 아니다.

- test 두 세트는 `outputs/eval_frozen/`에 고정했다. 이후 버전은 모두 같은 test로 잰다. 조립 단계는 이 test와 문자 유사도 0.7 이상인 요청을 학습에서 뺀다.
- 벤치마크 판독 표본은 7개 모델에서 143건씩 뽑았다(문항당 응답 하나). 판독 둘이 기존 라벨을 보지 않고 따로 판정해 969건(96.8%)이 일치했고, 엇갈린 32건 중 31건은 세 번째 판독의 다수결로 정했다. 셋이 모두 다른 1건은 뺐다. 세 판독이 같은 절차를 따르므로 같은 쪽으로 틀리는 오류는 이 일치율에 드러나지 않는다.
- 점검 과정에서 train/test를 다시 나눴기 때문에 새 실제 응답 test의 93%가 점검 전 모델의 학습 데이터에 들어 있다. 점검 전 모델은 벤치마크로만 비교한다.

## 4. v0.3이 떨어진 이유

원인 분리 실험은 하지 않았다. 아래는 이미 있는 예측과 학습 데이터로 한 분석이고, 인과는 추정이다.

### 무엇이 바뀌었나

| 항목 | v0.2.5 | v0.3 |
|---|--:|--:|
| 학습 예제 | 17,136 | 20,957 |
| 적법 / 위반 / 확인필요 | 48.7% / 44.5% / 6.8% | 51.7% / 41.2% / 7.2% |
| 경고 표현이 든 적법 예제 | 57.5% | 62.4% |
| 경고 표현이 든 위반 예제 | 26.5% | 36.7% |
| 조건형 규칙 12개의 위반 예제 | 2,096 | 1,836 |
| 의료광고의 위반·확인필요 비율 | 0.57 | 0.52 |
| 최대 길이 (초과로 빠진 예제) | 4096 (402건) | 6144 (0건) |
| 최종 선택 체크포인트 | 1,700 / 2,092 스텝 | 2,000 / 2,620 스텝 |

v0.3은 v0.2.5에 프론티어형 합성 3,054건과 조건형 규칙 재생성 1,356건을 더하고, 조건형 규칙의 자백형 위반본 589건을 뺐다.

### 어디서 떨어졌나

| 위반·확인필요 응답의 재현율 | 실제 응답 test v0.2.5 → v0.3 | 판독 표본 v0.2.5 → v0.3 | 판독 표본 판정 모델 |
|---|--:|--:|--:|
| 응답에 경고 표현이 있음 | 0.815 → 0.796 | 0.622 → **0.574** | 0.598 |
| 응답에 경고 표현이 없음 | 0.953 → 0.927 | 0.931 → 0.914 | 0.914 |
| 조건형 규칙 위반 | 0.885 → 0.847 | 0.754 → **0.688** | 0.710 |
| 그 밖의 규칙 위반 | 0.904 → 0.891 | 0.746 → 0.725 | 0.735 |

- v0.2.5가 맞히고 v0.3이 틀린 예제는 실제 응답 test 40건, 판독 표본 29건이고, 반대는 17건, 15건이다.
- 판독 표본에서 새로 놓친 위반 21건 중 71%가 경고를 담은 응답이고, 81%가 소제목·✅/⚠️ 표시를 쓰는 긴 응답이다(중앙값 1,899자). 의료광고가 14건이다.
- 실제 응답 test에서 새로 놓친 위반 24건 중 62%가 조건형 규칙이다(test 전체 위반의 40%).
- 실제 응답 test의 새 오탐 16건 중 7건이 부동산 규칙(UP-REALESTATE)이다. 이 규칙의 위반 학습 예제가 200건에서 258건으로 늘었다.

### 추정한 원인

**① 판정 모델 일치 필터가 어려운 예제를 걸러냈다 (가장 유력).** 새 합성 데이터는 판정 모델과 라벨이 일치한 것만 남겼다. 그런데 판정 모델이 틀리는 예제가 바로 가드에게 가르치려던 예제였다.

| 프론티어형 버전 | 의도한 라벨 | 판정 모델 일치 | 불일치로 빠짐 |
|---|---|--:|--:|
| 금지 행위를 해 주겠다고 수락 | 위반 | 328 | 195 (적법 191) |
| 금지 행위를 해 주겠다고 수락 (조건형 규칙) | 확인필요 | 34 | 269 |
| 엉뚱한 주의만 달고 허용 (조건형 규칙) | 확인필요 | 31 | 268 |
| 경고 뒤 위반 버전 건넴 | 위반 | 836 | 12 |
| 긴 경고 후 적법 대안 | 적법 | 1,268 | 167 |

수락형 위반의 37%가 판정 모델이 적법이라 해서 빠졌고, 조건형 규칙의 수락·엉뚱경고형은 거의 다 빠졌다. 남은 데이터는 판정 모델도 맞히는 쉬운 예제에 치우쳤다. 그 결과 v0.3은 판정 모델이 약한 곳에서 판정 모델만큼 약해졌다. 경고가 섞인 위반 재현율(0.574)이 판정 모델(0.598)과 비슷해졌고, 판정 모델과의 일치도도 91.2%에서 91.6%로 올랐다. 판정 모델 기준 벤치마크에서만 v0.3이 가장 높게 나온 것도 이것으로 설명된다.

**② 조건형 규칙의 위반 신호가 약해졌다.** 자백형 위반본 589건을 뺐고, 조건형 재생성분은 설계상 위반을 만들지 않았으며, 그 확인필요본도 64%를 판정 모델이 위반으로 봐서 빠졌다. 조건형 규칙의 위반 예제가 12% 줄고 확인필요·적법은 늘었다(예: 심의 없이 게재 위반 132 → 89, 확인필요 27 → 72). 조건형 규칙 위반의 재현율이 가장 많이 떨어졌다(판독 표본 −6.6%p).

**③ 경고가 붙은 적법 예제가 늘었다.** 긴 경고 후 적법 대안 1,200건과 조건형 경고본 736건이 학습에 더해져, 경고 표현이 든 적법 예제가 크게 늘었다. 경고 뒤 위반 버전을 건네는 합성 위반 예제도 늘었지만, 합성본은 "그래도 진행하신다면"처럼 위반 부분이 뚜렷하게 나뉘어 있어 실제 모델 응답과 모양이 다르다. 실제 모델은 경고 속이나 대안 문구 안에 금지 요소를 섞는 경우가 많다.

**④ 적법 비율이 늘고 의료광고의 위반 비율이 줄었다.** 새로 놓친 위반이 의료광고에 몰려 있다(실제 응답 test 24건 중 18건, 판독 표본 21건 중 14건).

**배제하거나 확인하지 못한 요인**

- 학습 중단과 재개: 두 학습 모두 시간 제한으로 끊겼다가 체크포인트에서 이어 학습했지만, 최종 선택된 체크포인트(2,000스텝)는 중단 전에 저장된 것이다. 재개는 결과에 영향이 없다.
- 최대 길이: v0.2.5를 v0.3과 같은 6144 토큰, 1 epoch로 학습하면 실제 응답 test F1이 0.897로 v0.2.5(0.912)보다 낮았다. epoch 수와 섞여 있어 길이만의 효과는 가를 수 없다.
- 검증 세트: v0.3은 새 합성 데이터가 든 검증 세트로 체크포인트를 골랐다. 선택이 합성 문체 쪽으로 기울었을 수 있으나 확인하지 않았다.

### 다음에 바꿀 것

- 새 데이터를 판정 모델 일치만으로 거르지 않는다. 판정 모델이 틀리는 유형(수락형 위반, 경고 속 위반, 조건형 규칙에서 사실이 드러난 위반)은 판독으로 확정하거나 실제 모델 응답에서 모은다.
- 조건형 규칙은 요청에 사실이 드러난 위반 예제를 확인필요본과 함께 둔다.
- 라벨 비율과 도메인 비율을 v0.2.5 수준으로 맞추고, 경고가 붙은 적법 예제와 경고 속 위반 예제의 비율을 맞춘다.
- 체크포인트는 실제 응답 검증 세트로 고른다.

## 5. 처음 보는 규칙 (hold-out)

## 6. 가드를 붙인 전/후

벤치마크 7개 모델의 저장된 응답 15,260건에 v0.2.5를 돌리고, 위반·확인필요로 판정한 응답 끝에 규칙표 기반 고지를 붙여 벤치마크 채점기로 다시 채점했다. 고지에는 규칙 이름과 조문, 금지 내용(확인필요면 조건), 규칙표의 허용 칸(대안), 문제 구간이 들어간다. 판정한 응답에는 모두 붙이므로 대조군 오탐의 비용도 과잉경고 증가로 그대로 드러난다.

| 모델 | 위반 인지 strict 전 → 후 | 과잉경고 전 → 후 | 최소쌍 양쪽 전 → 후 | strict 탈락 중 가드 적발 | 그중 규칙까지 맞힘 | 적발 시 규칙 일치 | 대조군 오탐 |
|---|--:|--:|--:|--:|--:|--:|--:|
| GLM-4.7-Flash | 6% → 60% | 16% → 21% | 0/29 → 26/29 | 83% | 76% | 92% | 10% |
| EXAONE-4.5-33B-FP8 | 24% → 71% | 19% → 25% | 0/29 → 25/29 | 82% | 75% | 92% | 9% |
| kanana-2-30b-a3b | 22% → 63% | 16% → 19% | 1/29 → 23/29 | 76% | 72% | 95% | 6% |
| Qwen3.8-27B | 28% → 61% | 31% → 35% | 1/29 → 19/29 | 70% | 63% | 91% | 8% |
| gemma-4-31B-it | 44% → 75% | 32% → 37% | 2/29 → 23/29 | 72% | 65% | 91% | 9% |
| claude-opus-5 | 77% → 81% | 22% → 25% | 18/29 → 19/29 | 33% | 29% | 93% | 4% |
| gpt-5.6-sol | 11% → 18% | 6% → 6% | 0/29 → 3/29 | 15% | 14% | 97% | 2% |

- 오픈 모델 5종은 위반 인지가 22~44%에서 60~75%로, 최소쌍 양쪽을 맞힌 쌍이 0~2쌍에서 19~26쌍으로 늘었다. 대조군 응답의 6~10%에 고지가 잘못 붙어 과잉경고가 3~6%p 늘었다.
- '후' 수치는 사용자가 산출물을 쓰기 전에 고지를 받는지를 잰다. 산출물에서 위반 부분이 사라진다는 뜻은 아니다.

**strict 탈락이 곧 위반 산출물은 아니다.** strict는 조문을 짚고 금지 내용을 말해야 통과하므로, 금지 사실을 말했지만 조문을 대지 않은 적법 응답도 탈락한다.

| 모델 | strict 탈락 | 그중 lenient 통과 | 판독 표본에서 실제 위반 산출물 | 그중 가드 적발 |
|---|--:|--:|--:|--:|
| GLM-4.7-Flash | 1,297 | 51% | 85/89 | 73/85 |
| EXAONE-4.5-33B-FP8 | 994 | 53% | 58/63 | 53/58 |
| kanana-2-30b-a3b | 1,000 | 46% | 57/63 | 46/57 |
| Qwen3.8-27B | 872 | 65% | 50/56 | 43/50 |
| gemma-4-31B-it | 774 | 63% | 41/44 | 32/41 |
| gpt-5.6-sol | 1,125 | 78% | 24/84 | 15/24 |
| claude-opus-5 | 170 | 81% | 3/10 | 2/3 |

오픈 모델은 strict 탈락 응답의 89~96%가 실제 위반 산출물이지만, gpt-5.6-sol은 29%, claude-opus-5는 30%다. 두 모델의 '후' 수치가 거의 오르지 않는 것은 가드가 놓쳐서가 아니라, 고지를 붙일 위반 산출물이 적어서다.

## 8. 한계

- 판독은 법률 전문가의 검토를 거치지 않았다. 여러 판독이 같은 절차를 따르므로 공통된 판단 오류는 일치율에 드러나지 않는다.
- 점검하지 않은 실제 응답 train은 기존 라벨과 보강한 판정이 일치한 것만 남겼다. 점검한 표본으로 추정한 라벨 정확도는 약 95%다.
- 4절의 원인은 학습을 다시 돌려 확인한 것이 아니라, 예측과 데이터 분포에서 추정한 것이다.
- 벤치마크 판독 표본은 모델당 143건이라 모델별 수치의 불확실성이 크다.
