# K-RegGen Guard — 라벨 점검과 버전별 실험

작업 2026-09-23 ~ 11-09 · **현재 버전 v0.8c** (Qwen3-4B-Instruct-2507 + LoRA)

학습 데이터·모델 가중치·원시 응답은 저장소에 포함하지 않았다. 학습 데이터에는 모델이 실제로 작성한 위법 산출물이 그대로 들어 있어 공개하지 않는다. 데이터 정리는 `train/fixes.py`·`train/apply_audit.py`·`train/rewrite_endings.py`, 조립은 `train/build.py`·`train/merge.py`, 평가는 `eval/guard_eval.py`.

---

## 1. 요약

1. **학습·평가 라벨에 오류가 많았다.** 예제를 한 건씩 읽어 보니 라벨·규칙·구간이 틀렸거나 예제가 깨진 경우가 합성 데이터의 약 9%, 실제 응답의 약 22%였다. 지적된 1,090건은 기존 라벨을 가린 채 한 번 더 판독해 두 판독이 같은 쪽으로 바꾼 것만 고쳤다.
2. **기준으로 쓰던 판정 모델이 학습한 가드보다 부정확하다.** 두 번 판독한 벤치마크 응답 1,000건에서 판정 모델은 F1 0.79~0.80, 학습한 4B 가드는 0.829다. 판정 지침을 보강해도 0.793 → 0.801로 거의 오르지 않았다. 벤치마크의 주 지표를 이 1,000건으로 바꿨다.
3. **v0.8c가 현재 버전이다. 사전에 정한 채택 규칙으로 고른 버전이 아니다.** v0.8 학습 데이터에서 응답 모델 1종의 응답을 빼고 같은 설정으로 다시 학습했다. 실제 응답 test F1 0.932, 벤치마크 판독 표본 0.881이다. v0.5(0.931, 0.875)보다는 모든 평가에서 높지만 두 주 지표의 95% 구간이 0을 포함하고, v0.8(0.928, 0.899)보다는 판독 표본에서 낮다(−0.019, 구간 [−0.033, −0.004]). 그 전의 v0.8도 규칙상 '유지'였던 결과를 보고 채택한 것이었다(5절).
4. **점검 전후 모델의 성능 차이는 없다.** 벤치마크 판독 표본에서 +0.004이고 95% 구간이 0을 포함한다. 점검으로 얻은 것은 믿을 수 있는 평가 기준이다.
5. **v0.3은 오히려 나빠져 채택하지 않았다.** 프론티어형 합성 데이터와 조건형 규칙 재생성분을 더하고 자백형 위반본을 뺐더니 F1이 두 평가 세트에서 모두 약 0.02 떨어졌다(95% 구간이 0을 포함하지 않음).
6. **새 합성 데이터를 더하면 재현율이 떨어진다.** v0.3에서는 판정 모델 일치 필터가 어려운 예제를 걸러낸 것을 가장 유력한 원인으로 봤다. 그래서 v0.4에서 그 예제 1,293건을 두 번 판독해 되살리고 라벨 비율도 맞췄지만, 벤치마크 판독 표본 F1이 다시 0.023 떨어졌다(95% 구간이 0을 포함하지 않음). 필터는 원인의 일부일 뿐이고, 교사가 쓴 합성 응답을 더하는 것 자체가 실제 응답에서의 재현율을 깎는 것으로 보인다.
7. **라벨을 다시 판정한 것이 효과가 있었다(v0.5).** 실제 응답 학습 데이터 11,679건을 정확도가 높아진 새 판정 모델로 다시 판정하고, 기존 라벨과 엇갈린 1,746건을 두 판독자가 블라인드로 읽어 확정했다. 판독은 70%가 새 판정 쪽이었고, 기존에 적법이던 499건이 위반으로 바뀌었다. 데이터 양은 그대로인데 판독 표본 재현율이 0.748 → 0.798로 올랐다.
8. **실제 응답을 늘리면 처음 보는 모델에 강해지지만 오탐이 는다(v0.6, 채택 보류).** 학습에 쓰지 않은 오픈 모델 3종의 응답 6,678건을 더했더니 판독 표본 F1이 0.904로 더 올랐고, 프론티어 모델 응답의 커버리지가 크게 늘었다. 하지만 실제 응답 test에서는 적법 응답 오탐이 10.0% → 12.2%로 늘어 F1이 0.004 낮아, 사전에 정한 규칙상 채택하지 않았다.
9. **새 응답의 라벨도 판독으로 확정하니 오탐이 v0.5 수준으로 줄었다(v0.8).** v0.6의 새 응답 중 판정 모델과 v0.5 가드가 엇갈리거나 판정이 갈린 1,481건을 두 판독자가 읽어 확정했다. 실제 응답 test 오탐이 12.2% → 10.4%로 v0.5 수준에 가까워졌고, 벤치마크 쪽 이득은 대부분 남았다.
10. **처음 보는 규칙의 위반도 대체로 잡는다.** 규칙 5개를 학습에서 빼도 해당 위반의 재현율은 0.89 → 0.82로 줄었을 뿐이다. 규칙 ID를 맞히는 정도는 규칙마다 달라, CCTV·부동산 규칙은 그대로였고 목적 외 이용 규칙은 28건 중 4건만 맞혔다.
11. **1.7B도 라벨 재판정의 효과를 크게 받았지만, 데이터를 늘리면 오히려 떨어졌다.** v0.5 데이터로 학습한 1.7B는 판독 표본 F1이 0.781 → 0.871로 올라 4B v0.5(0.875)에 가까워졌다. v0.8 데이터로 학습하면 0.848로 떨어져(−0.022, 구간 [−0.041, −0.004]) 1.7B는 v0.5 데이터 버전을 쓴다. 1.7B의 실제 응답 test 적법 오탐은 14.5%로 4B보다 높다. 같은 규칙표를 준 gpt-oss-safeguard-20b(실제 응답 test 0.854, 판독 표본 0.764)는 정밀도는 높지만 위반을 많이 놓친다.
12. **가드(v0.8c)를 붙이면 고지 없이 나가는 위반·확인필요 산출물이 크게 준다.** 오픈 모델 5종은 응답의 41~64%에서 7~9%로, gpt-6.1-sol은 19%에서 5%로, claude-opus-5-5는 9%에서 3%로 줄었다. 판정 모델이 위반·확인필요로 본 응답 가운데 가드가 고지를 붙인 비율은 오픈 모델 84~87%, gpt-6.1-sol 71%, claude-opus-5-5 66%다. 적법한 응답에 고지가 잘못 붙는 비율은 3~6%다.

## 2. 평가 세트

| 세트 | 건수 | 라벨 | 용도 |
|---|--:|---|---|
| 실제 응답 test | 1,187 | 전부 두 번 판독해 확정 | 주 지표 |
| 합성 test | 576 | 점검 후 확정 | 보조 |
| 벤치마크 판독 표본 | 1,000 | 두 번 판독, 엇갈리면 세 번째 판독 다수결 | 주 지표 (채택 판정) |
| 7개 모델 판독 표본 | 1,000 | 위 표본의 오픈 모델 5종 714건 + 프론티어 2종 286건(같은 절차) | 보조 |
| 벤치마크 전체 | 15,260 | 판정 모델(판독 표본 기준 F1 0.936) | 보조 |

- test 두 세트는 `outputs/eval_frozen/`에 고정했다. 이후 버전은 모두 같은 test로 잰다. 조립 단계는 이 test와 문자 유사도 0.7 이상인 요청을 학습에서 뺀다.
- 벤치마크 판독 표본은 7개 모델에서 143건씩 뽑았다(문항당 응답 하나). 판독 둘이 기존 라벨을 보지 않고 따로 판정해 969건(96.8%)이 일치했고, 엇갈린 32건 중 31건은 세 번째 판독의 다수결로 정했다. 셋이 모두 다른 1건은 뺐다. 세 판독이 같은 절차를 따르므로 같은 쪽으로 틀리는 오류는 이 일치율에 드러나지 않는다.
- 2026년 10월 벤치마크 비교 모델을 바꾸면서, 판독 표본에서 빠진 모델 응답을 같은 절차로 판독한 새 모델 응답 286건으로 바꾼 7개 모델 판독 표본을 따로 만들었다. 채택 판정은 이전 버전과 같은 조건이 되도록 기존 판독 표본으로 한다.
- 점검 과정에서 train/test를 다시 나눴기 때문에 새 실제 응답 test의 93%가 점검 전 모델의 학습 데이터에 들어 있다. 점검 전 모델은 벤치마크로만 비교한다.

## 4. v0.3이 떨어진 이유

원인 분리 실험은 하지 않았다. 아래는 이미 있는 예측과 학습 데이터로 한 분석이고, 인과는 추정이다.

### 무엇이 바뀌었나

| 항목 | v0.2.5 | v0.3 |
|---|--:|--:|
| 학습 예제 | 17,136 | 20,957 |
| 적법 / 위반 / 확인필요 | 48.7% / 44.5% / 6.8% | 51.7% / 41.2% / 7.2% |
| 경고 표현이 든 적법 예제 | 57.5% | 62.4% |
| 경고 표현이 든 위반 예제 | 26.5% | 36.7% |
| 조건형 규칙 12개의 위반 예제 | 2,096 | 1,836 |
| 의료광고의 위반·확인필요 비율 | 0.57 | 0.52 |
| 최대 길이 (초과로 빠진 예제) | 4096 (402건) | 6144 (0건) |
| 최종 선택 체크포인트 | 1,700 / 2,092 스텝 | 2,000 / 2,620 스텝 |

v0.3은 v0.2.5에 프론티어형 합성 3,054건과 조건형 규칙 재생성 1,356건을 더하고, 조건형 규칙의 자백형 위반본 589건을 뺐다.

### 어디서 떨어졌나

| 위반·확인필요 응답의 재현율 | 실제 응답 test v0.2.5 → v0.3 | 판독 표본 v0.2.5 → v0.3 | 판독 표본 판정 모델 |
|---|--:|--:|--:|
| 응답에 경고 표현이 있음 | 0.815 → 0.796 | 0.622 → **0.574** | 0.598 |
| 응답에 경고 표현이 없음 | 0.953 → 0.927 | 0.931 → 0.914 | 0.914 |
| 조건형 규칙 위반 | 0.885 → 0.847 | 0.754 → **0.688** | 0.710 |
| 그 밖의 규칙 위반 | 0.904 → 0.891 | 0.746 → 0.725 | 0.735 |

- v0.2.5가 맞히고 v0.3이 틀린 예제는 실제 응답 test 40건, 판독 표본 29건이고, 반대는 17건, 15건이다.
- 판독 표본에서 새로 놓친 위반 21건 중 71%가 경고를 담은 응답이고, 81%가 소제목·✅/⚠️ 표시를 쓰는 긴 응답이다(중앙값 1,899자). 의료광고가 14건이다.
- 실제 응답 test에서 새로 놓친 위반 24건 중 62%가 조건형 규칙이다(test 전체 위반의 40%).
- 실제 응답 test의 새 오탐 16건 중 7건이 부동산 규칙(UP-REALESTATE)이다. 이 규칙의 위반 학습 예제가 200건에서 258건으로 늘었다.

### 추정한 원인

**① 판정 모델 일치 필터가 어려운 예제를 걸러냈다 (v0.4에서 원인의 일부로 확인).** 새 합성 데이터는 판정 모델과 라벨이 일치한 것만 남겼다. 그런데 판정 모델이 틀리는 예제가 바로 가드에게 가르치려던 예제였다.

| 프론티어형 버전 | 의도한 라벨 | 판정 모델 일치 | 불일치로 빠짐 |
|---|---|--:|--:|
| 금지 행위를 해 주겠다고 수락 | 위반 | 328 | 195 (적법 191) |
| 금지 행위를 해 주겠다고 수락 (조건형 규칙) | 확인필요 | 34 | 269 |
| 엉뚱한 주의만 달고 허용 (조건형 규칙) | 확인필요 | 31 | 268 |
| 경고 뒤 위반 버전 건넴 | 위반 | 836 | 12 |
| 긴 경고 후 적법 대안 | 적법 | 1,268 | 167 |

수락형 위반의 37%가 판정 모델이 적법이라 해서 빠졌고, 조건형 규칙의 수락·엉뚱경고형은 거의 다 빠졌다. 남은 데이터는 판정 모델도 맞히는 쉬운 예제에 치우쳤다. 그 결과 v0.3은 판정 모델이 약한 곳에서 판정 모델만큼 약해졌다. 경고가 섞인 위반 재현율(0.574)이 판정 모델(0.598)과 비슷해졌고, 판정 모델과의 일치도도 91.2%에서 91.6%로 올랐다. 판정 모델 기준 벤치마크에서만 v0.3이 가장 높게 나온 것도 이것으로 설명된다.

**② 조건형 규칙의 위반 신호가 약해졌다.** 자백형 위반본 589건을 뺐고, 조건형 재생성분은 설계상 위반을 만들지 않았으며, 그 확인필요본도 64%를 판정 모델이 위반으로 봐서 빠졌다. 조건형 규칙의 위반 예제가 12% 줄고 확인필요·적법은 늘었다(예: 심의 없이 게재 위반 132 → 89, 확인필요 27 → 72). 조건형 규칙 위반의 재현율이 가장 많이 떨어졌다(판독 표본 −6.6%p).

**③ 경고가 붙은 적법 예제가 늘었다.** 긴 경고 후 적법 대안 1,200건과 조건형 경고본 736건이 학습에 더해져, 경고 표현이 든 적법 예제가 크게 늘었다. 경고 뒤 위반 버전을 건네는 합성 위반 예제도 늘었지만, 합성본은 "그래도 진행하신다면"처럼 위반 부분이 뚜렷하게 나뉘어 있어 실제 모델 응답과 모양이 다르다. 실제 모델은 경고 속이나 대안 문구 안에 금지 요소를 섞는 경우가 많다.

**④ 적법 비율이 늘고 의료광고의 위반 비율이 줄었다.** 새로 놓친 위반이 의료광고에 몰려 있다(실제 응답 test 24건 중 18건, 판독 표본 21건 중 14건).

**배제하거나 확인하지 못한 요인**

- 학습 중단과 재개: 두 학습 모두 시간 제한으로 끊겼다가 체크포인트에서 이어 학습했지만, 최종 선택된 체크포인트(2,000스텝)는 중단 전에 저장된 것이다. 재개는 결과에 영향이 없다.
- 최대 길이: v0.2.5를 v0.3과 같은 6144 토큰, 1 epoch로 학습하면 실제 응답 test F1이 0.897로 v0.2.5(0.912)보다 낮았다. epoch 수와 섞여 있어 길이만의 효과는 가를 수 없다.
- 검증 세트: v0.3은 새 합성 데이터가 든 검증 세트로 체크포인트를 골랐다. 선택이 합성 문체 쪽으로 기울었을 수 있으나 확인하지 않았다.

### v0.4로 확인한 것

①을 확인하려고 v0.4를 만들었다. v0.2.5 학습 데이터는 그대로 두고(자백형 위반본도 남김), v0.3의 새 합성 데이터에 더해 판정 모델 불일치로 빠졌던 1,795건을 두 판독자가 기존 라벨을 보지 않고 다시 판정해 둘이 일치한 1,293건을 넣었다. 적법 비율은 v0.2.5 수준(48.6%)으로 맞췄고, 체크포인트는 실제 응답 검증 세트로 골랐다. 학습 설정은 v0.2.5와 같다. 채택 기준은 학습 전에 정했다(두 평가 모두 F1이 v0.2.5 이상이고 하나는 구간 하한 > 0이면 채택, 하나라도 구간 상한 < 0이면 기각).

| 항목 | v0.2.5 | v0.4 |
|---|--:|--:|
| 학습 예제 | 17,136 | 22,793 |
| 적법 / 위반 / 확인필요 | 48.7% / 44.5% / 6.8% | 48.6% / 44.2% / 7.2% |
| 조건형 규칙 위반 예제 | 2,084 | 3,187 |
| 실제 응답 test F1 (재현율) | 0.912 (0.897) | 0.905 (0.872) |
| 판독 표본 F1 (재현율) | 0.829 (0.748) | 0.806 (0.711) |

판독으로 되살린 예제 대부분이 판정 모델이 놓친 위반(조건형 재생성분 323건, 엉뚱한 경고형 241건, 수락형 210건)이었고, 조건형 규칙의 위반 예제도 53% 늘었는데 재현율은 v0.3과 비슷하게 떨어졌다. 정밀도와 적법 오탐은 나아졌다. 기준에 따라 기각했다.

따라서 ①~④는 v0.3의 하락을 다 설명하지 못한다. 두 버전에 공통인 것은 교사가 쓴 합성 응답을 4,000건 넘게 더했다는 점이다. 합성 응답은 위반 부분이 뚜렷하고 문체가 일정해서, 실제 모델 응답처럼 경고와 대안 속에 금지 요소가 섞인 경우를 가드가 덜 의심하게 만드는 것으로 보인다. 이 역시 원인 분리 실험으로 확인하지 않은 추정이다.

### 다음에 바꿀 것

- 성능을 올리려면 합성 응답보다 실제 모델 응답을 늘려야 한다. 학습에 쓰지 않은 오픈 모델의 응답을 더 모으고, 판정 모델이 틀리기 쉬운 유형은 판독으로 확정한다.
- 합성 데이터를 다시 더할 때는 한 종류씩 더해 실제 응답 test와 판독 표본으로 확인한다.

이 방향은 5절의 v0.5·v0.6에서 확인했다.

## 5. v0.5~v0.8c — 실제 응답의 라벨과 양

v0.3·v0.4에서 합성 데이터를 늘리면 실제 응답에서 재현율이 떨어진다는 것을 확인했다. 그래서 합성 데이터는 그대로 두고 실제 응답만 바꿨다. 학습 설정(2 epoch, 최대 4096 토큰, LoRA r16)과 채택 규칙(두 평가 모두 F1이 비교 대상 이상이고 한쪽 95% 구간 하한 > 0이면 채택, 한쪽이라도 상한 < 0이면 기각, 그 밖엔 유지)은 v0.4와 같고, 결과를 보기 전에 정했다.

### v0.5: 실제 응답 라벨을 다시 판정

v0.2.5의 실제 응답 라벨은 지침을 보강하기 전 판정 모델이 붙인 것이라, 그 판정 모델이 놓치던 위반이 적법으로 남아 있을 수 있었다. 벤치마크 측정에 쓰는 새 판정 모델(판독 표본 기준 F1 0.936)로 실제 응답 학습·검증 데이터 11,679건을 응답마다 3번씩 다시 판정했다.

| 기존 라벨 → 새 판정 | 건수 |
|---|--:|
| 같음 | 9,933 (85%) |
| 적법 → 위반·확인필요 | 1,163 |
| 위반·확인필요 → 적법 | 181 |
| 위반 ↔ 확인필요 | 402 |

엇갈린 1,746건은 두 판독자가 기존 라벨과 새 판정을 모두 보지 않고 따로 읽었다. 둘이 같은 라벨을 붙이고 둘 다 확신이 낮지 않은 1,041건만 그 라벨로 바꾸고, 판독이 엇갈리거나(170건) 둘 다 확신이 낮은(535건) 응답은 뺐다. 확정한 1,041건 중 726건(70%)이 새 판정과, 282건(27%)이 기존 라벨과 같았다. 기존에 적법이던 499건이 위반으로 바뀌었다.

그 결과 v0.5 학습 데이터는 16,465건(위반 48.3%, 적법 45.1%)으로 v0.2.5(17,136건)보다 조금 적다. 재현율이 실제 응답 test 0.897 → 0.943, 판독 표본 0.748 → 0.798로 올랐고 판독 표본 정밀도도 0.930 → 0.969로 올랐다. 실제 응답 test의 적법 오탐은 8.3% → 10.0%로 늘었다. 두 평가의 F1 차이가 모두 0보다 커서 채택했다.

### v0.6: 학습에 쓰지 않은 모델의 실제 응답 추가

v0.5에 학습·벤치마크에 쓰지 않은 오픈 모델 3종의 응답을 더했다. 요청은 v0.5 실제 응답의 학습·검증 요청 2,742개(test 요청 제외)를 그대로 썼다. 라벨은 새 판정 모델의 3번 판정이 모두 같은 것만 썼다. 판독은 거치지 않았다. 깨진 텍스트·언어 전환(616건)과 판정이 갈린 응답(805건)을 빼고 6,678건이 들어갔다(학습 데이터 22,891건).

| 평가 | v0.5 | v0.6 | 차이 [95% 구간] |
|---|--:|--:|--:|
| 실제 응답 test F1 | **0.931** | 0.926 | −0.004 [−0.014, +0.005] |
| 판독 표본 F1 | 0.875 | **0.904** | +0.030 [+0.010, +0.049] |
| 7개 모델 판독 표본 F1 | 0.876 | **0.913** | +0.037 [+0.018, +0.055] |
| 판독 표본 재현율 (claude-opus-5-5 / gpt-6.1-sol) | 0.36 / 0.75 | **0.86 / 0.88** | – |

v0.6은 벤치마크 응답, 특히 프론티어 모델 응답에서 크게 좋아졌다. 반면 학습 데이터와 같은 응답 모델 5종에서 나온 실제 응답 test에서는 적법 오탐이 10.0% → 12.2%로 늘어 F1이 조금 낮다. 규칙상 채택도 기각도 아니라 v0.5를 유지했다.

### v0.7: 문의형 응답을 뺀 추가 (한 번만 시도)

test에서 v0.6만 새로 낸 오탐 19건 중 12건이 "이래도 되나요?" 같은 문의형 요청의 응답이었다. 판독 없이 붙인 판정 모델 라벨이 문의형 응답을 사람 판독보다 엄격하게 보는 경향이 옮겨간 것으로 보고, v0.6의 추가분에서 문의형 요청의 응답 2,152건을 뺀 v0.7을 학습했다. 같은 test를 보며 계속 손보지 않도록 결과와 상관없이 한 번만 시도하기로 미리 정했다.

| 평가 | v0.5 | v0.6 | v0.7 | v0.7 − v0.5 [95% 구간] |
|---|--:|--:|--:|--:|
| 실제 응답 test F1 | **0.931** | 0.926 | 0.926 | −0.005 [−0.014, +0.005] |
| 실제 응답 test 적법 오탐 | **10.0%** | 12.2% | 11.7% | |
| 판독 표본 F1 | 0.875 | **0.904** | 0.891 | +0.016 [−0.003, +0.035] |

문의형을 빼도 실제 응답 test의 오탐은 거의 줄지 않았고(12.2% → 11.7%), v0.6이 벤치마크에서 얻은 이득은 절반가량 사라졌다. 오탐 증가의 원인은 문의형 라벨이 아니라 새 응답 모델의 데이터를 넣은 것 자체로 보인다. v0.7도 규칙상 유지에 해당해 현재 버전은 v0.5다.

v0.5와 v0.6은 쓰임새에 따라 갈린다. 학습 데이터와 같은 응답 모델 분포에서는 v0.5가 오탐이 적고, 학습에 없던 모델, 특히 프론티어 모델의 응답에는 v0.6이 더 많이 잡는다.

### 1.7B

같은 데이터로 1.7B도 학습했다. v0.5 데이터로는 판독 표본 F1이 0.781 → 0.871로 크게 올라 4B와 거의 같아졌다. v0.8 데이터로는 0.848로 v0.5 데이터보다 낮고 95% 구간 상한이 0보다 작아(−0.022 [−0.041, −0.004]) 기각했다. 새 모델 3종의 응답을 더하면 4B는 처음 보는 모델에 강해졌지만, 1.7B는 오히려 기존 판독 표본에서 재현율이 떨어졌다(0.824 → 0.784). 작은 모델은 응답 분포가 넓어진 데이터를 다 소화하지 못하는 것으로 보인다. 1.7B는 v0.5 데이터 버전을 쓴다.

### v0.8 채택 — 사전 규칙에서 벗어남 (2026-10-20)

사전 규칙으로는 v0.8이 '유지'에 해당한다. 판독 표본에서는 95% 구간 하한이 0보다 크지만, 실제 응답 test F1이 v0.5보다 0.003 낮아 "두 평가 모두 비교 대상 이상"이라는 채택 조건을 채우지 못한다.

그런데도 **v0.8을 현재 버전으로 정했다. 이는 결과를 본 뒤에 내린 결정이고, 사전 규칙에서 벗어난다.** 근거는 다음과 같다.

- 실제 응답 test의 차이(−0.003)는 95% 구간 [−0.012, +0.007] 안에 있고 0을 넉넉히 포함한다. 기각 기준(구간 상한 < 0)에도 걸리지 않는다.
- 나머지 평가는 모두 v0.8이 높다. 판독 표본, 7개 모델 판독 표본, 벤치마크 전체에서 F1이 오르고 세 구간 모두 0을 넘는다.
- 가드를 붙일 대상은 학습에 없던 다양한 모델이다. 실제 응답 test는 학습 데이터와 같은 응답 모델 5종에서 나온 것이라, 처음 보는 모델에 대한 성능은 판독 표본과 벤치마크가 더 잘 보여 준다.

이 결정 때문에 v0.8의 우위는 사전 규칙으로 확인된 결과라기보다 사후 판단으로 읽어야 한다. 실제 응답 test 기준으로는 v0.5와 v0.8의 차이를 가릴 수 없다.

## 7. 가드를 붙인 전/후

벤치마크 7개 모델의 저장된 응답 15,260건에 가드를 돌리고, 위반·확인필요로 판정한 응답 끝에 규칙표 기반 고지를 붙였다. 고지에는 규칙 이름과 조문, 금지 내용(확인필요면 조건), 규칙표의 허용 칸(대안), 문제 구간이 들어간다.

## 9. 한계

- 판독은 법률 전문가의 검토를 거치지 않았다. 여러 판독이 같은 절차를 따르므로 공통된 판단 오류는 일치율에 드러나지 않는다.
- 점검하지 않은 실제 응답 train은 기존 라벨과 보강한 판정이 일치한 것만 남겼다. 점검한 표본으로 추정한 라벨 정확도는 약 95%다.
- 현재 버전(v0.8c)은 사전 규칙으로 고른 것이 아니다(5절). v0.5와는 두 주 지표에서 차이를 가릴 수 없고, 벤치마크 판독 표본에서는 v0.8보다 낮다.
- 4절의 원인과 5절의 v0.6 오탐 원인은 학습을 다시 돌려 확인한 것이 아니라, 예측과 데이터 분포에서 추정한 것이다.
- v0.5의 재판정에서 판독은 엇갈린 응답만 했다. 기존 라벨과 새 판정이 같은 9,933건에 같은 쪽으로 틀린 라벨이 남아 있을 수 있다.
- 벤치마크 판독 표본은 모델당 143건이라 모델별 수치의 불확실성이 크다.
